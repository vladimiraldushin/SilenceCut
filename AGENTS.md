# SilenceCut — заметки для AI-агентов

## Как собирать и тестировать

Проект генерируется XcodeGen: после добавления/удаления файлов в `Sources/` или `Tests/` нужен `xcodegen generate` (иначе новый файл не попадёт в таргет).

Тесты `RETimelineTests` и `REExportTests` рендерят настоящие видеофикстуры через
`AVAssetWriter`, поэтому прогон идёт минутами. По ходу работы гоняй только затронутый тест
(`-only-testing:RETimelineTests/имяТеста`), полный набор — один раз перед коммитом.
Записывая фикстуру, ОБЯЗАТЕЛЬНО жди `isReadyForMoreMediaData`: без проверки вход бросает
исключение и роняет весь прогон модуля, а не один тест.

```bash
xcodegen generate
xcodebuild -project SilenceCut.xcodeproj -scheme SilenceCut -configuration Debug build
xcodebuild -project SilenceCut.xcodeproj -scheme SilenceCut -configuration Debug test -destination 'platform=macOS'
xcodebuild -project SilenceCut.xcodeproj -scheme SilenceCut-iOS -configuration Debug \
  -destination 'generic/platform=iOS Simulator' CODE_SIGNING_ALLOWED=NO build
```

Схема `SilenceCut` прогоняет все тест-таргеты: `RECoreTests`, `REAudioAnalysisTests`, `RETimelineTests`, `REExportTests`. У каждого фреймворка своя схема (`RECore`, `RETimeline`, `REAudioAnalysis`, `REExport`, `REUI`) со своими тестами — модуль можно прогнать, не собирая приложение целиком.

## Архитектура

Слои (зависимости строго в одну сторону): `RECore` → `RETimeline` / `REAudioAnalysis` → `REExport` → `REUI` → приложения (`SilenceCutApp` для macOS, `SilenceCutIOSApp` для iOS). Оба приложения используют один `MainEditorView` с платформенными ветками.

Опорные точки, которые стоит знать перед правками:

- **`RECore/EditTimeline`** — модель монтажа (EDL). Устроена как **хребет плюс перебивки**: `clips` — связанные видео и звук, `overlays` — картинка без звука поверх хребта. Речь всегда идёт с хребта одним непрерывным потоком, поэтому детекция пауз и субтитры остаются однозначными. Исходный файл никогда не меняется.
- **`RECore/MediaSource`** — реестр исходников внутри `EditTimeline.sources`. Клипы ссылаются на источник по `sourceID`, а не хранят URL: метаданные кадра, bookmark и замер громкости лежат в одном месте, и сборщику композиции не нужно грузить `AVURLAsset` на каждом клипе.
- **`RECore/EditTimeline.applyRemovals(_:)` и `applyInsertion(at:duration:)`** — ЕДИНСТВЕННЫЙ путь укорачивания и раздвигания таймлайна. Любой вырез обязан идти через него, иначе перебивки останутся на старых местах. Кадры перебивки, попавшие в вырезанный кусок, исчезают вместе с ним: вырез внутри разбивает перебивку надвое, вырез с краю подрезает. `splitClipBySpeechRanges` режет паузы внутри одного клипа и не трогает соседние. Вставка симметрична вырезу: перебивка, накрывшая точку вставки, распадается надвое, иначе её картинка поехала бы поверх нового материала. `moveClip(id:toBoundary:)` принимает НОМЕР СТЫКА в текущем массиве, а не конечный индекс — перетаскивание на таймлайне даёт именно стык, и пересчёт с учётом изъятия клипа спрятан внутри.
- **`RETimeline/CompositionBuilder.build(from:options:)`** — ЕДИНСТВЕННОЕ место, где строится `AVComposition`. Через него идут и превью, и экспорт, поэтому «что видно, то и получится». Три дорожки: видео хребта, видео перебивок, звук хребта. Трансформация пер-клиповая: свой поворот, своё кадрирование (`ClipFraming`), свой джамп-кат зум. Порядок слоёв в `layerInstructions` (первый = верхний) зафиксирован тестом `OverlayCompositionTests` на цветных фикстурах — документация в этом месте невнятна, менять по памяти нельзя.
- **`REExport/ExportService.export(...)`** — однопроходный экспорт: `AVAssetReaderVideoCompositionOutput` → отрисовка субтитров Core Graphics прямо на кадрах → `AVAssetWriter` с битрейтом пресета. Никаких промежуточных файлов и второго кодирования. Звук читается и пишется в фиксированном формате проекта (48 кГц стерео): с разнородными исходниками «на усмотрение системы» разъезжается. Отмена — через `ExportCancellationToken`.
- **`REAudioAnalysis/AudioAnalysis.analyze(url:)`** — один потоковый проход по звуку даёт и waveform, и `RMSCache`. Кеши держатся **на источник**, поэтому детекция тишины пересчитывается мгновенно, без чтения файла. Память константная — важно для часовых роликов.
- **`RECore/ProjectStore`** — проект это самостоятельный документ `.silencecut` в любом месте диска, а не sidecar рядом с видео: с несколькими источниками привязка к одному ролику потеряла смысл. Путь помнит вьюмодель (`projectFileURL`), автосохранение пишет туда через 2 секунды после правки. Пока место не выбрано, `scheduleAutosave` молчит — правки живут в памяти, а вьюмодель поднимает флаг `needsSaveLocation`, по которому интерфейс показывает панель сохранения (модальные диалоги AppKit живут в слое UI, не в модели). Файлы первой версии (источник хранился прямо в клипе) мигрируют при чтении; метаданные кадра, которых у них нет, догружает `backfillMissingMetadata` уже после открытия. Старые sidecar-файлы — валидные документы и открываются через «Открыть проект…».
- **`RECore/GraphicClip` и `EditTimeline.graphics`** — третий слой: титры с прозрачностью, выше и хребта, и перебивок. Надпись обязана оставаться читаемой, когда под ней идёт b-roll, поэтому перебивки для этого не годятся — они непрозрачны и заменяют кадр. Исходник должен быть с альфой (ProRes 4444); что встроенный компоновщик AVFoundation её уважает, зафиксировано тестом `AlphaCompositingTests` — документация об этом молчит. Кадрирования у графики намеренно нет: она рендерится сразу в размер холста, и масштабирование только размыло бы текст.
- **Слой графики раскладывается на НЕСКОЛЬКО дорожек композиции.** Раньше она была одна, и наехавший по времени титр молча пропадал — а это рабочий случай: бегущая строка идёт через весь ролик, подписи говорящих появляются поверх неё. Раскладка жадная: клип занимает первую дорожку, свободную к его началу. Верхней оказывается заведённая последней. Тест `overlappingGraphicsAllSurvive`.
- **`TimelineClip.gain` и `framingEnd`** — громкость и наезд кадра ПО КЛИПУ. Гейн источника тут бессилен: микрофон пропадает не на весь дубль, а на отдельные реплики. Наезд собирается через `setTransformRamp`, а не пару `setTransform` — последняя даёт ступеньку. У клипа СВОЙ `encode(to:)`: добавляя поле, впиши его туда, иначе правка молча потеряется при сохранении. Сторожит `clipSurvivesRoundTripWithEveryField`.
- **`silencecut level-audio`** выравнивает тихие клипы по медиане ролика. Не трогает клипы без речи: речь отличается от фона не уровнем, а РАЗМАХОМ коротких окон громкости — у слогов разброс больше десятка децибел, у ровного фона почти нулевой. Подъём ограничен запасом до пика, иначе получится хрип.
- **`silencecut frame`** — снимок СОБРАННОГО монтажа, с кадрированием и графикой. Судить о картинке по расшифровке речи нельзя: беззвучные куски в тексте не видны вовсе.
- **`RECore/PinnedClip`** — общий протокол перебивок и графики. Всё, что приколото ко времени таймлайна, обязано одинаково реагировать на вырез и вставку; дублировать эту математику для двух слоёв значило бы обречь их разъехаться. Тест `cutMovesOverlayAndGraphicIdentically` это сторожит.
- **CLI `silencecut`** (таргет `silencecut-cli`) — управление проектом снаружи: `new`, `info`, `canvas`, `list`, `validate`, `add-graphic`, `move-graphic`, `remove-graphic`. Читающие команды печатают JSON, ошибки идут в stderr — инструментом пользуется языковая модель. RECore компилируется ВНУТРЬ бинаря, а не линкуется фреймворком: его зовут из чужих репозиториев и из PATH, где никакого `@rpath` на папку сборки нет. Установка: `scripts/install-cli.sh`.
- **`REUI/ProjectFileWatcher`** — приложение подхватывает правки CLI. Следит за ПАПКОЙ, а не за файлом: `ProjectStore` пишет атомарно, и дескриптор старого инода после подмены событий не приносит. Отпечаток файла читается через `FileManager`, а НЕ через `URL.resourceValues` — последний кеширует значения, события приходят, но слежение каждый раз решает «ничего не изменилось». Задержка 0,35 с нужна потому, что первое событие прилетает на создание временного файла.
- **`REUI/ProjectHTTPServer`** — localhost:8787, `GET /project`, `GET /health`, `POST /reload`. Существует ради одной вещи, недоступной CLI: узнать, какой проект сейчас ОТКРЫТ. Только чтение и перечитывание: правки идут через CLI, а сервер, умеющий менять проект, был бы дырой — любой процесс на машине может постучаться на localhost.
- **Титры рендерит Remotion** в `~/Projects/tessera-video-studio`: шаблоны в `studio/src/silencecut/`, склейка в `tools/silencecut/add-graphic.mjs`, скилл `silencecut-graphics`. Порядок работы важен: СНАЧАЛА резать паузы, ПОТОМ ставить титры — графика едет за монтажом и после выреза останется на своих секундах, но разъедется по смыслу.
- **`RECore/RecentProjectsStore`** — список недавних проектов в UserDefaults для стартового экрана (`REUI/ProjectBrowserView`). Метаданные (длительность, число клипов) лежат в самой строке списка, чтобы экран рисовался без разбора десятка JSON'ов. Совпадение записей — по стандартизованному пути файла.
- **Субтитры** хранятся в ТАЙМЛАЙН-времени (транскрибация идёт по смонтированному звуку), поэтому маппинг source↔timeline для них не нужен.
- **Мультиклиповое редактирование — только macOS.** iOS собирается и открывает такие проекты на просмотр и экспорт, но вторую дорожку там не редактируют. Спека: `docs/superpowers/specs/2026-08-10-multiclip-timeline-design.md`.

## Горячие клавиши на macOS

Разделение простое: сочетания с ⌘ живут в меню (`.commands` в `SilenceCutApp.swift`), одиночные клавиши — в `NSEvent`-мониторе там же. Монитор ОБЯЗАН пропускать события с ⌘/⌃/⌥: без этой проверки он глотал ⌘O, потому что keyCode 31 — это буква O, и пункт меню «Открыть» не срабатывал.

Перехват идёт в `NSEvent`-мониторе в `SilenceCutApp.swift`. Он обязан пропускать события, когда фокус в текстовом поле: проверяется и флаг `viewModel.isTextEditingActive` (его выставляет `@FocusState` в списке субтитров), и цепочка responder'ов. Не добавляй `.onKeyPress` на родительские вью — SwiftUI перехватит пробел раньше `TextField`, и в субтитрах нельзя будет поставить пробел.

## Git: .git вне синка Яндекс.Диска (с 11.07.2026)

Яндекс.Диск повреждал `.git` (терял объекты, плодил конфликтные копии ref'ов), поэтому git-dir вынесен из синка: он лежит в `~/.git-store/silencecut.git`, а `.git` в корне проекта — однострочный файл-указатель `gitdir: ../../../.git-store/silencecut.git`. НЕ заменять этот файл папкой и НЕ переписывать путь на абсолютный (относительный путь одинаков на всех машинах с папкой в `~/Yandex.Disk.localized/`).

Настройка git на новой машине (файлы проекта уже приходят через Диск вместе с указателем):

```bash
git clone --no-checkout --separate-git-dir="$HOME/.git-store/silencecut.git" \
  https://github.com/vladimiraldushin/SilenceCut.git "${TMPDIR:-/tmp}/tmp-clone"
rm -rf "${TMPDIR:-/tmp}/tmp-clone"   # временный worktree не нужен — файлы уже в папке
cd "$HOME/Yandex.Disk.localized/Монтаж/silencecut"
git config core.worktree "$PWD"
git reset   # заполнить индекс из HEAD; git status должен стать чистым
```
