## Грабли, на которые уже наступили

- **Запущенное приложение старой сборки затирает новые поля проекта.** Оно следит за
  файлом, подхватывает правку CLI и сохраняет обратно своим кодировщиком. Поля `gain` и
  `framingEnd` так исчезли дважды. Перед правкой проекта через CLI приложение надо либо
  закрыть, либо пересобрать.
- **`TimelineClip` имеет собственный `encode(to:)`** — добавленное поле нужно вписывать
  туда руками, иначе оно молча теряется при сохранении. Сторожит тест
  `clipSurvivesRoundTripWithEveryField`.
- **Проверять звук измерением, а не на слух.** Дважды казалось, что правка применилась,
  хотя уровни на выходе не менялись. Быстрый способ: экспорт + `ffmpeg -af volumedetect`
  по нужным отрезкам.
- **Судить о картинке по расшифровке речи нельзя.** Пролёт коробки NO SMOKE
  (`IMG_5152.MP4`, весь клип) я записал в отсутствующие, потому что он беззвучный.
  Для визуальных вопросов — `silencecut frame --sheet`.

## Полезные команды

```bash
silencecut info ~/Downloads/EWA_Reporters_reels.silencecut
silencecut list <проект> --graphics          # что и когда стоит на слое графики
silencecut list <проект> --clips             # гейн и наличие наезда по клипам
silencecut frame <проект> --count 15 --sheet # посмотреть монтаж глазами
silencecut level-audio <проект>              # без --apply только показывает
silencecut transcribe <проект>               # расшифровка, в проект не пишет
silencecut export <проект> --out готовое.mp4
```
